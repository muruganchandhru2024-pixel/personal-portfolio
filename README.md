## ⚡ Overview

**CHANDHRU.EXE** is a production-grade personal developer portfolio that combines a **Futuristic Dark Neon Cyberpunk Aesthetic** with an **Interactive 3D Three.js WebGL Experience**.

Built with Next.js 14 App Router, React Three Fiber, Framer Motion, and Tailwind CSS, this portfolio showcases verified engineering capabilities, academic credentials from **Sri Krishna College of Technology (SKCT)**, professional internship experience at **FortuMars AI Technologies**, and flagship computer vision projects.

---

## 🌟 Key Features

1. **Futuristic Developer OS Boot Sequence**:
   - High-tech terminal boot-up sequence under 1.5 seconds.
   - Session storage persistence to avoid repeat delays; respects `prefers-reduced-motion` and includes instant `ESC` skip.

5. **Animated Vertical Experience Timeline ("The Journey So Far")**:

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js 18+ installed on your machine.

### Installation

```bash
# Clone the repository
git clone https://github.com/muruganchandhru2024-pixel/personal-portfolio.git

# Navigate to directory
cd personal-portfolio

# Install dependencies
npm install --legacy-peer-deps
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
npm run build
```
